# Historical platform notes — use the common Linux setup

This earlier guide is retained for existing links, not as the primary deployment
target. Use [Linux setup](linux-setup.md) and [background service](background-service.md)
on any systemd-based Linux distribution meeting the stated prerequisites. No
per-distribution tailoring or OS-release submission is required. Python 3.9+ is
supported, including 3.13.5. Optional immutable-system/gaming-session considerations
are in [platform-notes.md](platform-notes.md).

Game-specific configuration is separate from Linux deployment; see the optional
[Running Train integration plan](running-train.md).
